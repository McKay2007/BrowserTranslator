# ReadMate 划词翻译（PDF 版）

一个轻量的 Chrome/Edge 浏览器插件：阅读外文网页时，选中或双击看不懂的词句，立刻弹出准确译文，还可以复制、朗读。

## 功能

- 划词 / 双击 / `Alt+T` 三种方式触发翻译，支持 15 种目标语言。
- 选中单词时显示英/美音标、简明释义，点「详细释义」展开分词性释义、短语、双语例句和词形变化。
- 「朗读原文」用原文语言发声，而不是朗读译文。
- 翻译气泡与「译」按钮跟随选中内容滚动，滚出屏幕自动关闭。
- 生词本收藏：本地保存，支持搜索、删除、清空。
- 可选有道、Google、MyMemory，或自定义 OpenAI 兼容大模型接口。
- 可打开本地 PDF，在保持原文排版的同时划词翻译（本副本新增）。

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 回车。
2. 打开右上角的「开发者模式」。
3. 点击左上角「加载已解压的扩展程序」。
4. 选择本仓库目录。
5. 安装后建议点击工具栏的拼图图标，把 ReadMate 固定到工具栏。

## 使用

- 选中任意文本，附近会出现蓝色「译」按钮，点击即可翻译。
- 双击一个单词，会自动翻译（可在设置中关闭）。
- 选中文本后按 `Alt+T` 也可翻译；快捷键可在 `chrome://extensions/shortcuts` 修改。
- 翻译气泡和「译」按钮会跟随选中的内容一起滚动；点击空白处、按 `Esc`，或把选中内容滚出屏幕，都会自动关闭。
- 气泡内可复制译文、朗读**原文**，失败时可点击「重试」。
- 选中单个单词时会额外显示**原词音标**（英式/美式）和简明释义；点「详细释义」可展开分词性的完整词义、常用短语、双语例句和词形变化。
- 选中单词时点「☆ 收藏」可加入**生词本**；点工具栏图标，在「生词本」标签页查看、搜索、删除或清空收藏。

## PDF 翻译

本副本新增了 PDF 划词翻译：点击工具栏图标，在弹出面板点「翻译 PDF 文件」，会在新标签页打开 PDF 查看器；再点「打开 PDF」选择文件（或直接把 PDF 拖进页面），即可像网页一样选中文字翻译。

说明：Chrome/Edge 自带 PDF 查看器不向扩展开放选中文字，所以这里用内置的 PDF.js（放在 `lib/` 目录）重新渲染 PDF 并生成可选中文字层。原网页划词功能不受影响。

PDF 查看器使用 PDF.js 原生文字层，并从同一页面的绘制指令读取字符宽度、字距、词距及定位信息，为可匹配的文本逐字建立选择边界，避免仅缩放整行造成的单词内部偏移，支持旋转页面。无法可靠匹配的文字及暂不支持的竖排、Type3 等字体保留原生文字层。提取选中文本时保留选择的起止位置，补齐文字片段之间的空格，合并段落中的换行，清理软连字符、常见字体连字和不可见字符。实际连字符和段落分隔会保留，避免修改复合词或公式。

PDF 中同样支持双击翻译、`Alt+T`、词典释义、朗读原文、生词收藏和滚动跟随。双击开关及翻译引擎沿用插件设置。快速换词时会忽略过期结果，关闭气泡后不会被迟到的请求重新打开。

PDF 单词翻译默认使用 280px 的紧凑卡片，简明释义最多显示三行，完整释义点击展开。句子翻译气泡最大宽度为 360px；两者均会根据窗口宽度收缩，操作按钮会换行。

PDF 工具栏默认开启「补齐词尾」：例如选区实际停在 `translati`，只差最后两个字母时，会补齐成 `translation`，并同步扩展高亮。只对从词首开始、已选至少三个字母、词尾剩余不超过两个字母的拉丁字母单词生效；不会追加下一个词或标点。需要精确选择词的一部分时可关闭此开关，偏好会保存在本地。拖动过程中不进行补齐，松开鼠标后才处理。

没有文字层的扫描页会提示需要 OCR，本项目尚未集成 OCR。缺少或错误的 PDF 字体编码映射仍可能造成乱码；文字层修复不能还原文件里缺失的字符。复杂多栏文件的选择顺序仍受 PDF 自身文字顺序影响。

修改插件代码后，请到扩展管理页点击「重新加载」，再关闭旧 PDF 查看器、重新打开文件；已打开的普通网页也需刷新。

## 翻译引擎

- 自动（默认）：目标为中文时优先有道，再依次回退 Google、MyMemory；目标为其他语言时依次 Google、MyMemory。
- 有道翻译：国内通常可访问，英中翻译较自然；仅支持译成简体中文。
- Google 翻译：覆盖语言多、质量高，但在部分网络环境可能无法访问。
- MyMemory：免费、无需密钥，可作为备用。
- 自定义大模型接口：兼容 OpenAI 格式，可填入 DeepSeek、OpenAI、Moonshot 等接口，获得更高质量译文。

选中单个单词时，插件会额外从有道词典拉取音标、分词性释义、常用短语、双语例句和词形变化（仅在可用时显示）。

收藏的生词保存在浏览器本地（`chrome.storage.local`），不会上传到任何服务器。

## 自定义接口示例

以 DeepSeek 为例：

- 接口地址：`https://api.deepseek.com/chat/completions`
- 模型名称：`deepseek-chat`
- API Key：在 DeepSeek 开放平台创建后粘贴

设置会自动同步到登录的 Chrome 账号。

## 隐私

译文请求会发送到你选择的翻译服务。插件只处理你选中的文本，不读取或上传其他页面内容。

## 目录结构

```text
.
├── manifest.json      # 插件清单
├── background.js      # 翻译请求与词典解析（service worker）
├── content.js         # 划词气泡、释义展示、收藏
├── popup.html         # 设置面板 + 生词本
├── popup.css
├── popup.js
├── viewer.html        # PDF 查看器
├── viewer.css         # PDF 页面及原生文字层样式
├── viewer.js          # PDF 渲染、文件切换、扫描页提示
├── pdf-selection.js   # PDF 选中文字提取与清理
├── pdf-text-geometry.js # 从绘制指令校准逐字符选区
├── lib/               # 内置 PDF.js、字体及解码资源
├── icons/             # 插件图标
└── test/              # Node 离线测试及浏览器 PDF 回归测试
```

## 开发

测试使用 Node 内置的 `vm` 模块在离线环境加载脚本并断言，无需安装依赖或启动浏览器：

```bash
cd test
node test-content.js
node test-translators.js
node test-dict-real.js
node test-pdf-text.js
node test-pdf-geometry.mjs
```

PDF 的真实 DOM 选取和排版回归测试：在项目根目录执行 `node test/serve-pdf-test.js`，浏览器打开 `http://127.0.0.1:8787/test/pdf-browser.html`。测试使用本地生成的三页 PDF 和模拟翻译接口，不发送联网翻译请求；检查字体位置、字宽、部分单词、跨行/段落选取、旋转页面、生词收藏和过期请求处理。结束后按 `Ctrl+C` 停止服务。

实际 PDF 的第一页对齐诊断：在已安装 `pdfplumber` 的 Python 环境执行 `python test/extract-pdf-geometry.py "文件路径.pdf"`，再通过上述本地服务打开 `http://127.0.0.1:8787/test/pdf-browser.html?alignment=1`。诊断关闭词尾补齐，将浏览器选区与独立提取的 PDF 坐标比较，并检查按原文位置取词是否完整。样本仅复制到本地 `tmp/pdfs/`；验证后删除该目录中的样本和坐标文件。
