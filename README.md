# ReadMate 划词翻译

一个轻量的 Chrome/Edge 浏览器插件：阅读外文网页时，选中或双击看不懂的词句，立刻弹出准确译文，还可以复制、朗读。

## 功能

- 划词 / 双击 / `Alt+T` 三种方式触发翻译，支持 15 种目标语言。
- 选中单词时显示英/美音标、简明释义，点「详细释义」展开分词性释义、短语、双语例句和词形变化。
- 「朗读原文」用原文语言发声，而不是朗读译文。
- 翻译气泡与「译」按钮跟随选中内容滚动，滚出屏幕自动关闭。
- 生词本收藏：本地保存，支持搜索、删除、清空。
- 可选有道、Google、MyMemory，或自定义 OpenAI 兼容大模型接口。

## 安装

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 回车。
2. 打开右上角的「开发者模式」。
3. 点击左上角「加载已解压的扩展程序」。
4. 选择本仓库目录。
5. 安装后建议点击工具栏的拼图图标，把 ReadMate 固定到工具栏。

## 使用

- 选中任意文本，附近会出现蓝色「译」按钮，点击即可翻译。
- 双击一个单词，会自动翻译（可在设置中关闭）。
- 选中文本后按 `Alt+T` 也可翻译；快捷键可在 `chrome://extensions/shortcuts` 修改。
- 翻译气泡和「译」按钮会跟随选中的内容一起滚动；点击空白处、按 `Esc`，或把选中内容滚出屏幕，都会自动关闭。
- 气泡内可复制译文、朗读**原文**，失败时可点击「重试」。
- 选中单个单词时会额外显示**原词音标**（英式/美式）和简明释义；点「详细释义」可展开分词性的完整词义、常用短语、双语例句和词形变化。
- 选中单词时点「☆ 收藏」可加入**生词本**；点工具栏图标，在「生词本」标签页查看、搜索、删除或清空收藏。

## 翻译引擎

- 自动（默认）：目标为中文时优先有道，再依次回退 Google、MyMemory；目标为其他语言时依次 Google、MyMemory。
- 有道翻译：国内通常可访问，英中翻译较自然；仅支持译成简体中文。
- Google 翻译：覆盖语言多、质量高，但在部分网络环境可能无法访问。
- MyMemory：免费、无需密钥，可作为备用。
- 自定义大模型接口：兼容 OpenAI 格式，可填入 DeepSeek、OpenAI、Moonshot 等接口，获得更高质量译文。

选中单个单词时，插件会额外从有道词典拉取音标、分词性释义、常用短语、双语例句和词形变化（仅在可用时显示）。

收藏的生词保存在浏览器本地（`chrome.storage.local`），不会上传到任何服务器。

## 自定义接口示例

以 DeepSeek 为例：

- 接口地址：`https://api.deepseek.com/chat/completions`
- 模型名称：`deepseek-chat`
- API Key：在 DeepSeek 开放平台创建后粘贴

设置会自动同步到登录的 Chrome 账号。

## 隐私

译文请求会发送到你选择的翻译服务。插件只处理你选中的文本，不读取或上传其他页面内容。

## 目录结构

```text
.
├── manifest.json      # 插件清单
├── background.js      # 翻译请求与词典解析（service worker）
├── content.js         # 划词气泡、释义展示、收藏
├── popup.html         # 设置面板 + 生词本
├── popup.css
├── popup.js
├── icons/             # 插件图标
└── test/              # Node 离线测试（无需浏览器）
```

## 开发

测试使用 Node 内置的 `vm` 模块在离线环境加载脚本并断言，无需安装依赖或启动浏览器：

```bash
cd test
node test-content.js
node test-translators.js
node test-dict-real.js
```
